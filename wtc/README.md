# 原世界贸易中心互动重建

在浏览器中探索原世贸双塔、WTC 3/4/5/6、广场及部分地下空间。采用着色器光线追踪渲染，支持自由漫游、建筑分层、剖切、昼夜变化和拍照模式。

## 操作

- 拖动鼠标转向，右键拖动平移，滚轮调整视场角。
- WASD 水平移动，Q/E 升降，Shift 加速。
- 单击构件查看建筑与材质信息，Esc 取消选中。
- 左侧调整画质、曝光和时间；右侧选择建筑、图层、剖切及预设视角。
- `PHOTO MODE` 调整画幅、焦距、景深、对焦、移轴与色彩，并设置成片质量。Esc 退出拍照模式。
- 截图支持 PNG；HDR 截图使用 JPEG XR（`.jxr`），需要支持该格式的查看器。

## 本地运行

在仓库根目录启动静态服务器：

```sh
python -m http.server 9031
```

打开 `http://localhost:9031/wtc/`。也可从 `perftests.html` 的“WTC 光线追踪”入口进入。

页面需要通过 HTTP/HTTPS 访问。优先使用 WebGPU，不可用时回退到 WebGL2；运行依赖随项目提供，无需安装或构建。首次加载会生成模型及光照缓存，后续访问可从浏览器 IndexedDB 恢复。

## 参考资料

建模参考 NIST、FEMA、Port Authority 原图及历史照片，资料链接见 [sources.json](data/sources.json)。缺少尺寸图的外观细节包含照片估计，模型并非完整竣工测量记录。

第三方依赖的许可与来源信息保存在 `vendor/`。
